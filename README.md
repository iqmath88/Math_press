# MathPress — محرر الرياضيات الاحترافي

نسخة تأسيسية أولية لمحرر مستندات رياضية يعمل كتطبيق ويب تقدمي (PWA)، مع أولوية للنص العربي والمعادلات القابلة للتحرير وحفظ المستندات محليًا.

## المتطلبات
- Node.js 20 أو أحدث
- npm حديث

## التشغيل
```bash
npm install
npm run dev
```
افتح عنوان التطوير الذي يعرضه Vite.

## البناء والاختبارات
```bash
npm run test
npm run build
npm run preview
```

## الوظائف الموجودة في الهيكل الأولي
- واجهة عربية RTL متجاوبة.
- مستندات MathPress بصيغة JSON مع الامتداد `.mathdoc`.
- حفظ تلقائي محلي باستخدام IndexedDB.
- فتح وتصدير المستندات.
- عنصر معادلة MathLive ومحرر مصدر LaTeX.
- معاينة ورقية A4 وأمر طباعة/حفظ PDF من المتصفح.
- إعداد PWA أولي وService Worker.

## حدود هذه النسخة
هذه نقطة انطلاق هندسية وليست إصدارًا جاهزًا لطباعة الملازم النهائية. تخطيط الصفحات الحالي مبدئي، ولا يضمن بعدُ توزيعًا دقيقًا متعدد الصفحات. كما أن فتح/حفظ الملفات يتم عبر منتقي الملفات ولا توجد مزامنة مجلد تلقائية. يجب اجتياز اختبارات PDF والمعادلات على Windows وiPad قبل الاعتماد الإنتاجي.

## ملاحظات تقنية
- يجب إبقاء مصدر LaTeX هو الحقيقة الأساسية للمعادلة وعدم تحويلها إلى صورة ثابتة.
- لا يُفترض أن خطوط الويب الخارجية متاحة دون اتصال؛ ينبغي تضمين خطوط مرخصة محليًا قبل اعتماد التشغيل دون إنترنت بالكامل.
- يجب تطوير ترقيم الصفحات والرؤوس والتذييلات وتقسيم المحتوى في مرحلة لاحقة.
- صيغة `.mathdoc` الحالية هي JSON نصي بامتداد خاص لتسهيل النقل؛ يمكن تحويلها إلى حاوية مضغوطة مستقبلًا.

## البنية (مسطحة بلا مجلدات فرعية)
- `App.tsx` و`main.tsx` — الواجهة ونقطة الدخول.
- `document.ts` و`types.ts` — نموذج المستند والتحقق.
- `storage.ts` — الحفظ المحلي (IndexedDB).
- `sw.js` و`manifest.webmanifest` — ملفات PWA، وتُنسخ تلقائيًا عند البناء.
- `document.test.ts` — الاختبارات.
- `ARCHITECTURE.md` و`QA-PLAN.md` — التوثيق.

## الخصوصية
لا توجد قاعدة بيانات سحابية أو حساب مستخدم في هذه النسخة. المستندات المحفوظة داخل التطبيق تبقى ضمن تخزين المتصفح على الجهاز، بينما ملفات `.mathdoc` المصدّرة تحفظ في المكان الذي يختاره المستخدم.
