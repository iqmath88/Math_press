# MathPress 0.2 — محرر الرياضيات الاحترافي

محرر مستندات عربي (RTL) للملازم والملخصات الرياضية، يعمل كتطبيق ويب تقدمي (PWA) على Windows وiPad، ويحفظ كل شيء محليًا على الجهاز.

## الجديد في 0.2
- **محرر نصوص كامل (TipTap):** عناوين، غامق/مائل/تسطير، منخفض/مرتفع، ألوان وتمييز، قوائم، اقتباسات، محاذاة، اتجاه RTL/LTR لكل فقرة، خطوط وأحجام.
- **معادلات داخل السطر وفي سطر مستقل** بمحرر MathLive المرئي، مع إدراج من مصدر LaTeX.
- **جداول** (صفوف، أعمدة، دمج خلايا، صف عناوين) و**صور** (تُصغَّر تلقائيًا، مع التحكم بالعرض).
- **صفحات A4 متعددة:** فواصل تلقائية بين الكتل، ترقيم «صفحة n من N»، نص تذييل اختياري، وفاصل صفحة يدوي.
- **خطوط مضمّنة** (أميري، نسخ، القاهرة، وخطوط المعادلات KaTeX) فلا تحتاج إنترنت بعد أول فتح.
- ترقية تلقائية لمستندات النسخة 0.1 المحفوظة.
- تحديثات التطبيق تصل فور النشر (الصفحة الرئيسية «الشبكة أولًا» في Service Worker).

## التشغيل
```bash
npm install
npm run dev
```
المتطلبات: Node.js 20+.

## البناء والاختبارات
```bash
npm run test

```
النشر على Vercel: يتعرف على Vite تلقائيًا (الأمر `npm run build`، المخرجات `dist`).

## طريقة الاستخدام السريعة
- زر **سطرية** يدرج معادلة داخل الفقرة، و**كتلة** يدرجها في سطر مستقل. اكتب مباشرة؛ على الآيباد تظهر لوحة MathLive تلقائيًا.
- داخل المعادلة: اضغط `\` لكتابة أمر LaTeX، والأسهم للخروج منها، وBackspace على معادلة فارغة لحذفها.
- **طباعة / PDF:** اختر «حفظ بتنسيق PDF». راجع عدد الصفحات قبل الحفظ.

## حدود هذه النسخة (مهم)
- **الفقرة الواحدة لا تنقسم بين صفحتين:** الكتلة التي لا تتسع تنتقل كاملة إلى الصفحة التالية، فقد يبقى فراغ أسفل الصفحة. الكتلة الأطول من صفحة كاملة (جدول طويل جدًا مثلًا) تمتد دون تقسيم دقيق.
- لا توجد رسوم بيانية/هندسية بعد (مخطط للنسخة 0.3 عبر JSXGraph).
- لا توجد رؤوس صفحات، ولا هوامش قابلة للتعديل من الواجهة (الهوامش 20/18 مم).
- فتح/حفظ الملفات عبر منتقي الملفات، ولا مزامنة مجلد تلقائية.
- طباعة المتصفح تحدد جودة PDF النهائي؛ يلزم اختبار فعلي على جهازك (انظر QA-PLAN.md).

## البنية (مسطحة بلا مجلدات فرعية)
- `main.tsx` · `App.tsx` · `Editor.tsx` · `Toolbar.tsx` — الواجهة.
- `extensions.ts` — إعداد محرر TipTap (اتجاه، حجم خط، صورة، فاصل صفحة…).
- `MathNodes.ts` — عقدتا المعادلة (داخل السطر / كتلة) فوق MathLive.
- `Pagination.ts` + `paginate.ts` — تقسيم الصفحات (القياس في المتصفح + المنطق الصرف).
- `document.ts` · `types.ts` · `storage.ts` — نموذج المستند (v2) والترقية والتخزين المحلي.
- `sw.js` · `manifest.webmanifest` · `*.png` — ملفات PWA، وتُنسخ تلقائيًا عند البناء.
- `*.test.ts` — الاختبارات. `ARCHITECTURE.md` · `QA-PLAN.md` — التوثيق.

## الخصوصية
لا حسابات ولا خادم. المستندات تبقى في تخزين المتصفح على جهازك، وملفات `.mathdoc` المصدّرة تُحفظ حيث تختار. التخزين المحلي للمتصفح قد يُمسح (مثلًا عند تنظيف بيانات Safari)، فصدّر نسخة احتياطية دوريًا.
