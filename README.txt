MathPress 0.1.1 — نسخة نشر ثابتة مسطحة
هذه إعادة تنفيذ للواجهة الأساسية من React إلى JavaScript مباشر لتجنب Vite وعملية البناء. ليست نسخة مطابقة حرفيا من المصدر. تحافظ على صيغة mathdoc وقاعدة IndexedDB الأصلية. لا تحذف بيانات المتصفح.
النشر: فك الضغط، ارفع جميع الملفات إلى جذر main في MathPress_faiz مع استبدال الملفات المتشابهة. من Settings > Pages اختر Deploy from a branch ثم main و /(root). لا يلزم npm. لا ترفع ZIP نفسه. الملفات القديمة من TypeScript لا تستدعيها الصفحة الجديدة.
MathLive 0.105.3 يحمل من CDN؛ يحتاج اتصالاً بالشبكة، ولا نضمن عمل المعادلات دون إنترنت. عند تعذر التحميل يبقى مصدر LaTeX قابلا للتحرير. الطباعة أولية؛ اختبر ملفات PDF الطويلة والهوامش والاتجاه قبل الاعتماد.
اختبار: تحقق من فتح الرابط، إضافة نص ومعادلة، حفظ وإعادة فتح مستند، تصدير واستيراد mathdoc، طباعة PDF. لم يتم اختبار المتصفح الحقيقي أو النشر الفعلي في هذه البيئة.
