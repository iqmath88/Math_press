MathPress v0.2.0 — إصلاح الاستقرار
ارفع جميع الملفات مباشرة إلى جذر مستودع GitHub Pages (main / root)، بما فيها .nojekyll. لا يحتاج إلى بناء.
يحافظ التطبيق على مخطط mathdoc وقاعدة IndexedDB السابقة عند استخدام نفس أصل الموقع. يستعيد آخر مستند ويستخدم سجل استرجاع محلي قبل الحفظ المؤجل. الاستيراد ينشئ نسخة مستقلة. النسخ الاحتياطي الشامل واسترجاعه متاحان من الشريط.
لا تحذف بيانات المتصفح؛ صدّر نسخة احتياطية دورياً. نقل التطبيق إلى أصل موقع مختلف لا ينقل البيانات تلقائياً. لا يضمن سجل الاسترجاع الحماية إذا منع المتصفح التخزين أو امتلأت المساحة أو فُتحت عدة تبويبات للتحرير في الوقت نفسه.
MathLive يعتمد على CDN؛ عند عدم توفره يظهر مصدر LaTeX، ولا تتاح طباعة المعادلات. التخزين المؤقت المحلي لا يضمن تشغيل المعادلات دون إنترنت. لم يتغير محرك تقسيم الصفحات في هذا الإصدار.
